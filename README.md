# 从零搭建个人技术博客

一份面向新手的完整实操指南：**域名 → Hugo 静态站 → Git 版本管理 → Cloudflare Pages 自动部署 → 自有域名 + HTTPS → 搜索引擎收录 → 长期备份**。

不依赖任何付费平台，一年成本只有一个域名（约 ¥60–90）。

## 你会得到什么

```
https://你的域名.com
```

- 自己的域名，自动签发 HTTPS 证书
- 内容是你本地的 Markdown 文件
- `git push` 后 1–2 分钟自动上线
- 全球可访问（中国大陆可访问，速度一般）
- 数据完全在自己手里，随时可以迁移

## 适合谁

- 想长期写技术笔记，不希望内容被平台绑架
- 希望链接十年后还能打开
- 愿意花 1–2 小时做一次性配置
- 能接受命令行操作
